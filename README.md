# CM 1_03 Scalzo Ideal Flow

A looping text animation of the ideal pricing flow:

Supplier price changes → Ingredient cost updates → Recipe cost changes → Margin moves outside target → The team reviews the product

Open `index.html` in a browser. Click anywhere on the canvas to replay. Above 600px wide the steps run left to right; at 600px and below they stack vertically.
